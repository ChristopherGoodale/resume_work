# Academic Experience Bank

Source of truth for `playbooks/academic.md`. Same rules as `achievements.md`: plain facts, nothing invented, no resume wording.

Fill in the entries yourself. Placeholders in `[brackets]` mean "not filled yet". The generator skips any entry that still contains a placeholder.

## How to write an entry

- **source**: the course, book, paper, or program, with institution or author.
- **dates**: when you studied it.
- **concept**: the specific idea or method learned (name it: Black-Scholes, Kalman filter, gradient boosting, not "finance").
- **applied in**: the id of a role fact or project in `achievements.md` (example: `Above Lending #3`, `Project: SEC EDGAR model`). Leave blank if not applied yet.
- **outcome**: what changed because of the application, with a number if one exists.
- **domain**: same tags as `achievements.md` (credit, forecasting, ML, BI, finance, and so on).
